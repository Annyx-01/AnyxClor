Koanyx ColorCode

A hands-on accessibility lab for **WCAG 2.1 Level AA**, delivered as a single `index.html` file. There are no frameworks, no CDNs, no build step, and no browser storage.

=What's inside
1. Keyboard & screen reader lab:** skip link, tabs, accordion, modal dialog, menu button, validated form, status toast and sortable table, plus a live keyboard event log and an ARIA inspector.
2. Contrast & magnification tester:** WCAG contrast checker with a "nearest passing color" suggestion, a page scanner, color-blindness simulation, text zoom, a 320px reflow test, a text-spacing test and a lens magnifier.
3. Remediation workshop:** a "Before" page with 19 deliberate failures, an "After" page with them fixed, and an issue tracker mapped to real WCAG 2.1 success criteria.
4. Audit report:** a WCAG 2.1 A and AA checklist by POUR principle, a test-method guide, and a report you can copy or print.

## Run it locally
Download `index.html` and open it in any modern browser.

Known limitations
This is a teaching simulation. Automated checks find only part of WCAG issues, so always test with real assistive technology (NVDA, JAWS, VoiceOver, TalkBack), browser zoom, and keyboard-only use.
