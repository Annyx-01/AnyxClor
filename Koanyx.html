      Module 4 - Audit report & checklist
      
 
      Honest note on automation
      
  
      Automated tools (axe DevTools, Lighthouse, WAVE) find only a portion of WCAG problems; estimates vary by study but are often well under half. Meaning, focus order, announcements and usability need manual testing.
      
  
      Test-method guide
      
  
      Keyboard-only
      Put the mouse away. Use Tab, Shift+Tab, Enter, Space, arrows and Esc. Check visible focus, logical order, no traps, a working skip link, and that every action is reachable.
      
  
      Screen readers
      NVDA with Firefox or Chrome (Windows, free); VoiceOver with Safari (macOS: Cmd+F5; iOS: Settings, Accessibility); TalkBack on Android; JAWS is commercial. Check names, roles, states, headings, landmarks and announcements.
      
  
      Zoom & magnification
      Zoom the browser to 200% and 400% (about 320 CSS px wide on a 1280px screen), try an OS magnifier, and apply the SC 1.4.12 text-spacing values.
      
  
      Contrast tools
      The Koanyx checker, the browser DevTools color picker, or a desktop analyzer such as the Colour Contrast Analyser.
      
  
      Automated tools
      Run axe DevTools, Lighthouse and WAVE first to catch easy issues, then continue by hand.
